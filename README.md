# Sobre este repositorio

Por ahora, entrar en la carpeta "introductions" se encuentran apuntes para lo antes mencionado, podria surgir la pregunta "realmente tengo que aprender esto?" no necesariamente pero abre muchas puertas puesto que la mejor forma de avanzar en el mundo laboral actual por ahora, quiza el dia de mañana salgan herramientas nuevas asi que lo que importa es poder trabajar comodo con lo que uno ya maneja, por ejemplo el flujo actual para un cientista de datos es

**Tengo una base** -> **Analizo las variables** -> **Evaluo supuestos** -> **Análisis Descriptivo/Predictivo** -> **Reporte** -> **Comunicacion de Resultados**
> dashboard si corresponde

Sin embargo, no todas las bases vienen listas para ser analizables desde el primer momento, tambien podria no existir una base de datos y se podria realizar el estudio desde cero, tambien podrian estar dispersos los datos y muchas otras circunstancias que nos impedirian partir lo que se nos ha enseñado con respecto a la parte estadistica. En el mundo laboral ocurre y es mejor equivocarse mientras aun se estudia que afuera, por ello tambien los apuntes hablan sobre las herramientas que se usan en la práctica como `git` y `uv` tanto para proyectos colaborativos como personales 

- `git`: su funcion es tener un control de versiones o historial de cambios y sirve para poder volver a un punto donde las cosas *"funcionaban"*
- `uv`: como el objetivo es aprender python y usarlo, uv simplifica el trabajo repetitivo para un cientista de datos como controlar dependencias y entornos virtuales

sobre los jupyter notebooks, son basicamente un Google Colab pero en local, tambien se debe saber que si haces un trabajo en local se puede subir a colab y trabajar desde la nube y viceversa, solo cambia quien se encarga del entorno y dependencias pero para ello está mi otro repositorio `my-workspace` que guía en ese sentido.
